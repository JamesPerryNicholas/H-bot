# 对话里连接服务

日期：2026-11-10

桌面应用已经有连接器目录、登录流程，以及 `list_connectors` / `request_connector`（在本会话里出连接卡片）。系统规则没有要求 Bot 调用这些工具，所以用户说要连接某个服务时，Bot 可能只把人指到设置页。

改动：在共享的团队规则里增加一条，要求每个 Bot（包括主 Bot）在用户要连接外部服务、或自己需要尚未连接的服务时，先调用 `list_connectors`，再在本会话里调用 `request_connector`（带 id 和简短用途），让连接卡片出现在对话里，而不是只指向设置。连接卡片只在本会话有效：在群里要先说明会回到自己的会话里询问，并在那里调用。若服务已连接，直接用它的工具。工具不可用时，告知用户并指向 设置 → 连接器。

本文不复制任何第三方产品文案。卡片行为、群聊限制和已有工具参数保持不变。
